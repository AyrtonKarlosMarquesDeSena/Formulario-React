# 📚 Cadastro de Curso

## 📖 Sobre o Projeto

Este projeto consiste em um formulário de cadastro de cursos desenvolvido em React, utilizando React Hook Form para gerenciamento dos formulários e Yup para validação dos dados.

O objetivo é oferecer uma experiência simples e intuitiva, validando os campos em tempo real e simulando o envio das informações.

---

## 🚀 Tecnologias Utilizadas

- React
- React Hook Form
- Yup
- CSS Modules

---

## ✨ Funcionalidades

- ✅ Cadastro de cursos
- ✅ Validação dos campos em tempo real
- ✅ Feedback visual para campos inválidos
- ✅ Simulação de envio assíncrono
- ✅ Limpeza automática do formulário após o envio

---

## 📝 Regras de Validação

| Campo | Regra |
|-------|-------|
| Nome | Obrigatório, entre 3 e 50 caracteres |
| Data | Obrigatória e deve ser uma data válida |
| Categoria | Obrigatória (Programação, Design, Marketing ou Outros) |
| Descrição | Obrigatória, entre 10 e 70 caracteres |
